================================================================================
  bao 出口报关文件编织助手 — 从 0 到 1 完整示例
================================================================================

【场景】
  客户发来发票.xlsx 和装箱单.xlsx，需要编织成出口报关单。
  本示例使用内置的示例文件演示。

================================================================================
  第一步：激活环境
================================================================================

  # 首次使用前执行一次：
  source ~/.zshrc

  # 之后每次使用，终端里输入：
  bao

  → 自动 cd 到 customs/bao 目录并激活 Python 虚拟环境
  → 提示符前出现 (venv) 表示已激活

================================================================================
  第三步：编织生成报关单
================================================================================

  bao build from-files \
    -i data/示例发票.xlsx \
    -p data/示例装箱单.xlsx \
    -o data/报关单_0521.xlsx \
    -s "苏州恒通纺织进出口有限公司"

  参数说明：
    -i   发票 Excel 文件路径（必填）
    -p   装箱单 Excel 文件路径（可选）
    -o   输出报关单 Excel 路径
    -s   境内发货人名称
    -c   统一社会信用代码（18位）
    -d   报关单号（留空自动生成）
    --save   同时归档到 SQLite 数据库

================================================================================
  示例数据说明
================================================================================

  示例文件位于 customs/bao/data/：

  示例发票.xlsx
    ├── 表头区：发票号、日期、买卖方、合同号、贸易术语、币制、起运港/目的港、船名等
    └── 数据区：3 行商品（序号/HS编码/品名/规格/数量/单价/总价/净重/毛重）

  示例装箱单.xlsx
    ├── 表头区：发票号、日期、发货人/收货人、包装、唛头
    └── 数据区：120 行装箱明细（箱号/品名/数量/净重/毛重/尺寸）

  生成脚本：data/gen.py（运行即重新生成示例文件）
    python data/gen.py

================================================================================
  适配你自己的 Excel 格式
================================================================================

  bao 通过列名映射自动识别 Excel 格式，支持中英文双语列名。

  如果你的发票列名不同，创建自定义映射：

  from bao.parsers.excel_parser import ExcelParser

  custom_map = {
      "seq":       ["编号", "No.", "行号"],
      "hs_code":   ["商品编码", "HS", "HS Code"],
      "name_zh":   ["产品名称", "货品"],
      "quantity":  ["Qty", "箱数"],
      ...
  }
  parser = ExcelParser(column_map=custom_map)
  parser.parse_invoice("贵司发票.xlsx")

  常见列名都能自动识别（序号/品名/HS编码/数量/单价/总价等
  的中英文变体），只需在遇到特殊格式时补充自定义映射。

================================================================================
  工作流程总结
================================================================================

  1. 客户发来 发票.xlsx + 装箱单.xlsx
  2. bao → 激活环境
  3. bao build preview -i 发票.xlsx → 核对数据
  4. bao build from-files -i 发票.xlsx -p 装箱单.xlsx -o 报关单.xlsx
  5. 打开 报关单.xlsx，核对无误后上传单一窗口
  6. 再加 --save 归档到数据库备查
  7. deactivate → 退出环境
