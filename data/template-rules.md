# 模板颜色规则

模板上传后，bao 自动按以下规则识别列行为：

## 颜色识别

| 表头填充色 | openpyxl 检测 | 行为 |
|-----------|-------------|------|
| 🟡 黄色 (FFFF00) | `fgColor.type == 'rgb'` | **自动匹配** -- 从输入数据或 hs_code.xlsx 取值填入 |
| ⬜ 灰色 (theme tint) | `fgColor.type == 'theme'` | **HS 匹配复制** -- 同品类的多行间内容保持一致 |

## 黄色列处理

程序自动根据关键词匹配黄色列表头，从以下来源填充：

| 字段关键词 | 数据来源 |
|-----------|------|
| Shipment ID | FBA 输入货件编号 |
| 箱号段 | FBA 输入箱子编号（标准化格式） |
| SKU | FBA 输入 MSKU |
| 英文品名 | hs_code.xlsx 按 HS 编码查表 |
| 中文品名 | hs_code.xlsx 按 HS 编码查表 |
| 材质 | hs_code.xlsx 按 HS 编码查表 |
| 用途 | hs_code.xlsx 按 HS 编码查表 |
| 海关编码 | hs_code.xlsx 按 HS 编码查表 |
| 每箱数量 / 总数量 | FBA 输入商品申报量 |
| 单箱重量 | FBA 输入箱子重量 |
| 单箱长/宽/高 | FBA 输入箱子尺寸 |
| 图片 | 自动插入（用户上传模板无嵌入图则回退本地默认模板图） |

> 黄色列匹配不到数据时**留空**，不填默认值。

## 灰色列处理

灰色列通过**海关编码匹配**，从模板示例行复制同品类数据：

| 灰色列典型字段 | 行为 |
|-------------|------|
| Brand 品牌 | 同一 HS 编码的所有行保持一致（从模板第1行示例取值） |
| 型号 | 同上 |
| 是否带电 | 同上 |
| 单位 | 同上 |
| 每套个数 | 同上 |

> 灰色列只要求在**同一品类内**保持一致。换 HS 编码后取另一品类的模板值。

## 匹配流程

```
FBA 输入文件
    ↓
fba_parser → 提取 MSKU、箱号、尺寸、进口海关编码
    ↓
weaver → 查 hs_code.xlsx → 获取黄色列值（品名、材质、用途、HS编码）
    ↓
exporter → 读模板表头颜色 → 分灰/黄
         → 黄色列：写入 weaver 数据
         → 灰色列：按 HS 编码匹配模板示例行 → 复制值
         → 图片：取用户模板嵌入图（无则回退本地模板）
```

## 使用方式

1. 上传品类模板（物流商提供，保留原有灰/黄色标注）
2. 上传 FBA 装箱数据（可含"进口海关编码"列用于精确匹配）
3. 生成装箱单

## 扩展品类

在 `data/hs_code.xlsx` 中添加新行即可。列结构：

| 中文品名 | 进口海关编码 | HS CODE | 英文品名 | 用途 | 材质 | 成分 | 备注 | 规格 |
|---------|------------|---------|---------|------|------|------|------|------|

备注列用作品牌名称。
